O que é um servidor web?

Um servidor web recebe requisições feitas por navegadores e devolve páginas, arquivos ou serviços pela internet.

Exemplo de fluxo

  1. O usuário acessa uma URL no navegador.
  2. O navegador envia uma requisição HTTP/HTTPS.
  3. O servidor processa o pedido.
  4. O servidor devolve a resposta.
  5. O navegador exibe a página.
